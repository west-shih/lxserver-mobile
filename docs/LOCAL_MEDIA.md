# 手机缓存与下载

当前实现面向前台播放及下载。LXServer 契约继续以 v2.2.0 为基线，不向服务器发起下载或删除操作。

## 用户行为

- 列表「已缓存 / 已下载」只表示手机存在完整音频文件，配色沿用 LX。
- 歌曲「… → 信息」分别展示本机和 LXServer 状态。
- 「我的音乐」右上角下载入口分为任务和已下载；支持暂停、重试、取消、播放和删除。
- 「头像 → 个人中心 → 缓存设置」默认2 GB，必须开启，可选256 MB至5 GB，旧关闭设置迁移为2 GB；清缓存不删下载。
- 下载按首选音质及既有降级规则解析；同档缓存可直接转为下载，播放正在缓存时共用传输。

播放内核和所有缓存/失效/淘汰规则统一维护在 [PLAYBACK_ENGINE.md](PLAYBACK_ENGINE.md)，后续优化更新该文档。

## 存储与生命周期

LocalMediaController 管理应用私有支持目录下的 `lx_audio/cache`、`lx_audio/downloads` 和 `index.json`。path_provider 获取目录，crypto 对服务器/账号/歌曲/音质生成稳定标识；二者原是传递依赖，现声明为直接依赖。

文件按服务器、账号隔离。索引只保存必要歌曲字段、音质、文件大小及任务，不保存音频 URL、Token 或密码。退出保留文件但隐藏该账号内容；卸载应用会删除私有文件，应用升级保留。

自动缓存按最近实际播放时间 LRU 淘汰，不额外偏向某个音质版本，当前播放文件受保护，切歌后再清理；清理/缩容时可暂时超出限制。只有完整传输且已被播放器接受的文件才登记缓存。未知长度或超过容量的流直接在线播放。主动下载独立保存，不参与缓存淘汰；重新下载成功后才替换旧文件。

AudioTransfer 共享网络传输和临时文件，验证状态、长度和音频头后原子重命名。CachedAudioProxy 仅监听本机回环地址，用临时随机路径提供范围读取；播放器接收普通 URL。切歌取消传输，启动清理残留临时文件。第三方请求不添加 LXServer 登录凭据。

## 离线与边界

此前安全保存的会话在服务器验证遇到网络错误时可恢复，供进入本机下载播放；鉴权拒绝仍退出登录。首次登录需要网络。下载封面成功保存在本机后可离线显示，成功获取的歌词分别随音频缓存和主动下载保存，离线时读取所播放音频所属的副本；具体存储及清理规则见播放内核文档。

下载队列串行、前台执行。暂停或进程重启后任务可重试，但当前文件从头下载，不是字节断点续传。没有后台下载服务、锁屏媒体控制或后台播放保证；iOS 尚未验证。

## 验证

`test/local_media_test.dart` 覆盖传输范围读取、内容校验、取消、完整文件登记、缓存/下载共用传输、清理保护、LRU、持久化与账号隔离、网络不可达时恢复会话。Android 夹具测试验证原生解码、下载列表和离线播放，不能替代真实平台音频编码验证。

## 决策参考

参考 Android Media3 对[有容量上限的网络缓存](https://developer.android.com/media/media3/exoplayer/network-stacks)及[持久下载](https://developer.android.com/media/media3/exoplayer/downloading-media)的职责划分；客户端继续使用 just_audio，并未引入 Media3 下载框架。

下载面板的音质行只更新勾选，顶部“下载”按钮才创建任务；不显示“按首选”快捷行，初始化仍按默认音质与歌曲信息选择。选择项使用普通文字和勾选，已下载文件使用与歌曲列表一致的彩色音质标签（未知音质灰色）。歌曲「信息」面板展示已有专辑、时长、歌曲 ID 和 LXServer 文件状态，QQ 同时具备数字 ID 和 MID 时分别展示。有可靠专辑 ID 的 QQ 和网易歌曲可打开专辑详情。本机下载及格式大小可在「本机下载」查看，歌曲行的已缓存标签可以打开清理确认。

下载音质复用播放音质的档位说明及已有大小。大小来自已有歌曲元数据，打开面板不探测。「已下载」列表在有效文件的大小旁显示已知格式，例如「4.3 MB · MP3」。

下载记录保存封面地址与来源平台，封面异步串行保存到本机，单张不超过 2 MiB，不阻塞音频下载。旧记录丢失的封面地址在同平台同歌曲 ID 的歌单/搜索信息返回时补齐；无网络且原地址已丢失时暂用占位图。
