# AI 任务与交接

AGENTS.md 是仓库统一规则入口，无需为每个 AI 工具复制一套同内容文档。
需求与验收查 REQUIREMENTS.md，源码版本与兼容范围查 COMPATIBILITY.md / upstream-baseline.json，接口依据查 API.md；状态和长期决策分别更新 ROADMAP.md、DECISIONS.md，对外开发变更归入 CHANGELOG.md。
新对话可以先说：“阅读 AGENTS.md、README.md 及相关文档，再检查当前仓库状态。”

## 单次任务模板

```text
目标：本次要实现的具体用户行为。
范围：涉及的页面、模块或接口。
依据：已有文档、服务端版本、设计或源码位置。
需求编号及上游基线：Rxxx；版本/tag/commit；需核对的文件/符号。
验收：可观察的成功与失败场景。
约束：平台、依赖、兼容性或明确不包含的功能。
执行：先检查现状，完成实现与必要验证，更新受影响文档。
```

## 示例

```text
实现服务器连接页。先核实目标 LXServer 的连接与鉴权协议，
记录 API 依据，再实现地址校验、连接中、成功和失败状态。
验收：地址可保存；错误地址有提示；凭据不出现在日志中。
本次不包含搜索和播放。完成后运行适用检查并报告结果。
```

## 中断或切换对话时的交接模板

```text
当前任务与验收条件：
已经完成：
修改文件：
已执行检查及结果：
尚未验证：
阻塞项或待确认事实：
下一步：
```

交接以当前代码和 Git 状态为准。不要将未完成任务标为完成，也不要将真实凭据写入交接记录。
