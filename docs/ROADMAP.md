# 开发路线

状态：未开始 / 进行中 / 已完成。仅在满足验收条件后标为已完成。

| 阶段 | 状态 | 工作范围 | 验收条件 |
| --- | --- | --- | --- |
| M0 基础与调研 | 进行中 | 文档、Flutter 初始化、环境检查、API 调研 | Android 可启动；记录服务端版本与核心接口证据 |
| M1 最小播放闭环 | 未开始 | 连接配置、鉴权、搜索、播放、队列 | 真机可从搜索结果播放歌曲；断网和无播放地址时有明确反馈 |
| M2 播放可靠性 | 未开始 | 后台播放、锁屏/通知栏、耳机、打断、队列持久化 | 验证熄屏、切后台、来电/其他音频打断、拔耳机及连续切歌 |
| M3 音乐体验 | 未开始 | 歌词、音质、歌单浏览、收藏、排行榜 | 已支持能力与 API 清单对应；音质失败有处理；歌词随进度更新 |
| M4 用户数据同步 | 未开始 | 歌单编辑、同步、失败恢复 | 明确服务器权威数据与冲突策略；失败可重试且不会重复写入 |
| M5 本地与离线 | 未开始 | 缓存、下载、存储管理 | 下载可恢复/重试；离线可播放；清缓存不误删下载 |
| M6 双平台与发布 | 未开始 | iOS 验证、权限、签名、安装包、发布说明 | Android/iOS 真机通过核心场景；无凭据进入仓库或安装包 |

## 下一步

1. 检查 Flutter SDK、Android 工具链和可用设备。
2. 确认应用标识、最低平台版本并创建 Flutter 工程。
3. 读取目标 LXServer 版本源码或文档，完善 docs/API.md。
4. 按 M1 分成小任务，每个任务给出运行结果和验收记录。

尽早安排 iOS 设备验证；M6 是集中验收阶段，不代表此前不考虑平台差异。
