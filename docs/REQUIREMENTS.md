# 需求与验收清单

本表维护当前结果，不是聊天记录。代码已实现不等于真实部署验收；服务端基线和证据等级见 [COMPATIBILITY.md](COMPATIBILITY.md)。里程碑只在 ROADMAP.md 维护，长期技术选择只在 DECISIONS.md 维护。

| 编号 | 需求/验收行为 | 当前状态及验证 |
| --- | --- | --- |
| R001 | Android 优先、Flutter 保留 iOS 边界；只用 LXServer 原生 API | Android 已运行；iOS 工程生成但未构建；API.md 记录基线 |
| R002 | 输入服务器地址、普通账号登录；本机恢复会话，不保存密码 | 已实现，单元/组件及模拟器夹具通过；真实部署权限待完整验收 |
| R003 | 多平台及聚合搜索；已明确禁用的平台不展示，未知不误隐藏 | 已实现，music_features_test、login_test、集成测试 |
| R004 | 搜索播放、共享队列、迷你/独立播放器，异步结果不串歌 | 已实现前台流程；后台、锁屏、打断待做 |
| R005 | 展示我的喜欢、个人歌单、收藏歌手/专辑及在线歌单 | 已实现只读，模拟器夹具通过；编辑同步写入未实现 |
| R006 | 白绿紧凑 UI，小搜索框；筛选随内容滚动，避免重复大标题 | 已实现；compact_layout_test 验证长列表与窄屏 |
| R007 | 左右滑动封面/歌词、LRC 翻译/高亮/点击跳转 | 已实现基础 LRC；逐字/罗马音待做 |
| R008 | 音质按歌曲信息选择；平台与最高已标注音质独立标签，长歌手名不遮挡 | 已实现；平台/音质配色对齐 LX v2.2.0。音质面板具体证据在主列表、未知档位折叠、明确不支持不展示；标签不保证当前解析源可用 |
| R009 | 全局首选、当前播放、下载音质分别设置 | 已实现：个人中心保存首选，播放页菜单切换，不改变首选或歌曲长期成功档位；下载独立选档。未播放歌曲不提供播放音质入口；组件及 Android 夹具验证 |
| R010 | 每首歌成功档位长期沿用，链接失效只刷新同档；不因 6 小时到期探测高档 | 已实现；remembered_quality_test 覆盖一周及重启、首选变更、主动重试、原档失败。记录按服务器/账号/源配置隔离，最多 200 条 LRU；注销或配置变化会清除 |
| R011 | 服务端已有文件优先，同档换解析源后再降级，恢复中不冒出中间错误 | 已实现；playback_recovery_test 与真实 404 静音 WAV 模拟器夹具验证；不跨平台换歌，不自动下载到服务器 |
| R012 | 收藏封面、歌曲封面字段兼容与网易 CDN 请求头 | 已实现；本地 HTTP 解码测试、真机 403 诊断；修复后目标页面显示待用户复核 |
| R013 | 明确源码版本、需求编号、决策和验证记录；模糊/内核需求优先查上游 | 已建立 AGENTS、COMPATIBILITY、只读基线核对脚本、需求表和 CHANGELOG；运行时版本自动识别待做 |
| R014 | 手机音频文件缓存、离线下载、存储管理 | 已实现完整文件缓存、前台下载、容量与实际播放 LRU 清理、已下载播放、离线恢复已有会话；暂停后从头重试当前文件，后台服务与断点续传未实现，详见 LOCAL_MEDIA.md |
| R015 | 后台播放、通知/锁屏控制、耳机与系统音频打断 | 未实现，需 Android 真机验证 |
| R016 | 歌单/收藏编辑与同步、排行榜、iOS 验收与发布 | 待实现/分阶段验收，见 ROADMAP |
| R017 | 展示歌曲“已缓存/已下载”状态，并明确存储位置 | 列表仅展示本机完整文件：已下载蓝、已缓存绿；服务器已有文件放在「… → 信息」的 LXServer 区域 |
| R018 | 下载入口位于我的音乐顶栏；头像进入个人中心；播放页直接访问歌曲操作 | 已实现；个人中心集中缓存设置、下载统计、账号与退出；保留收藏下拉刷新，移除顶栏刷新。播放页“…”将“音质选择”置于“信息”上方、隐藏立即播放，列表“…”无音质入口，信息页只读；标签共用 SongMetadata；歌名/作者/标签紧凑成组，更多按钮不撑高标签行。personal_center_test 覆盖入口导航及封面/歌词菜单；真机观感待验收 |
| R019 | 四种播放模式、本机记住选择；顺序播完停止 | 已实现顺序、列表循环、单曲循环、随机；随机不立即重复同首，手动下一首在单曲循环下仍切歌。comments_mode_test 覆盖候选索引及模式交互；系统后台行为未验证 |
| R020 | 从播放页查看当前平台歌曲评论 | 已实现 LXServer v2.2.0 原生评论接口、最热/最新、分页、已有回复和点赞数只读展示；请求代际避免旧分类覆盖新响应。Mock 契约/权限/异常和组件测试通过，真实平台评论可用性待联调 |
| R021 | 精简歌曲信息与下载交互 | 已实现：歌曲“信息”页以“存储”为标题，分本机/LXServer；本机缓存可确认清理，不重复下载入口；音质只在播放页菜单提供；下载面板勾选后点击顶部按钮才建任务，不显示“按首选”；已下载列表音质按 LX 配色展示，未知音质灰色。comments_mode_test 覆盖勾选不创建任务及信息页无下载入口；local_media_test 覆盖实际播放 LRU 与单曲清理保护，Android 夹具回归通过 |
| R022 | 下载封面与平台跨启动恢复 | 已实现封面地址持久化、本机封面保存及离线复用；旧记录按平台歌曲 ID 从歌单/搜索补齐。local_media_test 覆盖图片解码、重启无请求复用、删除清理及跨平台不误修复；下载任务和已下载列表统一展示平台标签 |

需求改变时更新原条目的最终行为、状态和测试依据；行为被替代时在 DECISIONS 留下“已替代”关系，不另造一份冲突规则。修复发布前归入 CHANGELOG 的 Unreleased，不擅自打 tag、发布或修改远端。
