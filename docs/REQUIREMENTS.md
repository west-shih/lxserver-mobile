## 歌单浏览与操作验收

- R025：依据 [已确认原型](design/playlist-detail-prototype.png) 实现封面信息区（96px 原封面、19 号标题、平台及可用创作者/播放量/日期/简介）和独立紧凑播放工具栏。缺失字段不占位，简介可展开；收藏跳转保留同平台/原 ID 的已缓存列表日期，详情无日期且无缓存时保持缺省，不伪造自建歌单创建时间；个人歌单缺少原平台元数据时不伪造。信息区随列表滚动，收起后导航显示 17 号可滚动标题。搜索由右上角图标展开，隐藏头部，匹配歌名/歌手/专辑；清除与取消回到首页，返回键先退出搜索/选择模式。默认连续，每页数量可选 10/20/30/50/100，默认 20；单页结果隐藏分页栏，保留 32px 紧凑分页及底部播放器。歌曲行保留封面、平台/音质/本机状态与更多菜单，筛选/分页不改变已加载队列。collection_management_test、playlist_prototype_test、scrolling_title_test 覆盖搜索取消、头部滚走、元数据缺省、窄屏/大字体、封面重载及标题滚动；已检查个人/外部/搜索三种实际 Flutter 渲染，Android Debug 构建及覆盖安装通过；手机锁屏，新版触摸/键盘体验待验收。
- R026：编辑入口采用三横线加勾图标；编辑收起头部和迷你播放器，左侧圆形勾选在封面前，右侧为拖动柄，顶部全选/已选数量/完成。跨页保留选择，全选作用于已加载歌曲。底部提供下一首播放、收藏到歌单、下载、删除。下一首播放去重并紧接当前歌曲，不打断播放；无当前歌曲时形成暂停待播队列。下载先选档再明确确认，取消不创建任务。私人歌单（含系统列表的歌曲）可删除及拖动排序，分页时只在当前页内拖动；排序点完成保存，返回可保存/放弃/继续。删除需确认，与待保存排序合并为一次写入；不移除本机下载或当前播放队列。外部原歌单只读，删除/排序须在私人副本操作。最新快照保留未知字段，排序前检查原顺序，拒绝覆盖已变化的目标；无跨设备原子保证，见 UPSTREAM_LIMITATIONS。Mock 覆盖真实指针拖动、失败保留草稿、只读限制、窄屏大字体及快照读回失败；真实写入、多设备同步和下载待验收。
- R005：系统列表无重命名/删除菜单；自建歌单通过名称输入保存重命名、删除需确认；外部在线歌单支持确认后完整收藏/取消收藏，关联在线歌单可完整刷新歌曲及非空原始封面并打开原始在线详情；缺失封面响应保留已有图，详情响应只读歌单重载的封面变化。Mock 验证删除保留其他列表/字段、系统列表保护、刷新跨页去重及重复页中止。Android 实例已只读核实服务端封面、原详情图片及图片 HTTP 200，并通过重载恢复列表显示；不保存实际歌单名或图片地址。Mock 覆盖封面解析、写入与缺失保留。真实部署写入、其他设备可见性与多设备并发待验证；无并发事务保证。
