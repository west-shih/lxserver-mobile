## R028 歌手与专辑

专辑搜索、歌手专辑页与“我的收藏”的已知平台专辑共用卡片：封面贴边且圆角为 0，仅由外层 12px 圆角裁剪，文字区内边距 10；收藏为封面右上角 24px 小圆标（图标 15），操作区域保留 40px，距封面边缘 2px。无中央播放或下载按钮，点封面/文字进入详情；收藏不触发导航。标题最多两行，底部歌手左对齐、平台标签贴右，底距 10；不固定预留空日期行。有 publishTime 时在标题下显示发行日期，无字段不补造；新收藏保存已有 publishTime，旧收藏缺失日期保持缺省，不逐张请求详情，行高按当前批次有无日期计算，保留大字体适配。

已实现源码/Mock 范围：搜索栏头像换歌曲/歌手/专辑菜单，歌手/专辑平台为账号可用与网易/QQ 交集，单平台检索；卡片收藏、详情收藏及“我的”统一跳转详情。歌手轻量数量统计、浅灰折叠简介、歌曲热门/最新及专辑列表；专辑播放、确认选档下载及可靠歌手身份跳转，名称无箭头，平台标签紧邻详情导航标题，无英文别名头及无效更多菜单。已加载歌曲作为统一队列，搜索卡片及详情歌曲沿用列表浏览设置，歌手专辑页按原生分页加载更多。不实现不喜欢。

“我的收藏”的歌手仍为列表，专辑为共用卡片；未知 source 保留文字列表并标记平台未知。compact_layout_test 在 1/1.6 倍字体下检查收藏专辑卡片、发行日期以及页签反复切换后筛选栏位置不变。歌手与专辑收藏统一使用详情导航栏右侧固定位置的爱心，已收藏为粉色实心、未收藏为空心；专辑简介下不再放收藏/下载按钮，下载通过歌曲菜单或多选进入，头像 80，右侧姓名固定靠上，姓名行最小 44、统计行预留最小 20，数量晚返回不移动姓名/爱心；数量先专辑后歌曲，无底色和边框，姓名左缘对齐统计图标。导航平台徽标相对文字中心做局部视觉偏移，随字体缩放。保留歌曲/专辑下划线切换及热门/最新选择，标签点击不显示整块水波底色。播放工具栏位于切换栏下，复用歌单的紧凑播放组件，随滚动吸附，与歌曲列表统一 lxCanvas 底色且无吸附阴影变色，专辑标签下隐藏。数量只显示实际载入的歌曲数，去掉“已加载”文字；右侧多选支持跨页保留、全选已载入歌曲、下一首播放/收藏到歌单/选档确认下载，原平台列表不提供删除或排序；返回先退出选择模式，保存期间阻止退出。简介上距 8、信息区底距 0、标签栏高 44，展开/收起紧凑置于右下。专辑详情也使用相同播放与选择组件，收藏位于导航栏，下载位于歌曲菜单/多选操作。

`entity_search_test` 的 14 项测试覆盖接口参数、交集、空平台、过期响应、远页直接读取/缓存、后页缺总数、重复页、整表字段保留、回读失败、会话隔离、窄屏大字、取消下载，以及导航栏固定收藏入口、播放栏吸附不遮挡标签及切换专辑时隐藏；新增回归覆盖数量晚到时姓名与导航收藏入口位置不变，相关 13 项测试及 flutter analyze 通过（此前完整 189 项通过）。真实服务端读写、播放/下载和触摸观感待验收。


## 歌单浏览与操作验收

- R005/R025/R026 流畅度：封面按物理显示尺寸解码，文件状态更新只重建歌曲标签区域；歌单保存进度提示固定占位。相关封面、排序、歌曲编辑、原型及紧凑布局组件测试和 flutter analyze 通过；Android 16/120Hz 真机已安装 profile 构建，当前分页歌单连续快速往返滑动两轮采集 386/353 帧：构建 P95 为 3.036/3.145ms，栅格 P95 为 2.866/2.565ms，分别有 5/6 帧的构建或栅格阶段超过 8.33ms；不能据此宣称已消除顿挫。同代码由 debug 换为 profile 后，用户确认快速滚动“明显顺滑了”，构建模式是此次体感差异的重要因素。debug 不作为流畅度验收依据；长列表及拖拽流畅度仍待专项复核。
