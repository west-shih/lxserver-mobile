## 已知能力限制

日期字段缺失、原平台歌单写入边界及全量快照并发限制统一记录于 [UPSTREAM_LIMITATIONS.md](UPSTREAM_LIMITATIONS.md)。私人副本歌曲可通过现有快照接口增删/排序，不归为服务端不支持。

## 日常匹配流程

可执行只读核对：`powershell -File scripts/check-upstream.ps1`。其他检出目录可传 `-UpstreamPath C:/path/to/lx_server`。脚本核对 package、tag、HEAD 与工作区，不拉取、不切分支、不改上游；不匹配时要求先审查差异，而不是自动覆盖基线。

1. 任务开始先查本页及基线文件；对模糊或内核优化先读目标版本相关源码、网页调用链、服务端实现。
2. 记录语义版本、tag、commit、相关文件/符号。语义版本相同不保证二次构建和 fork 内容相同。
3. 换服务端版本时，单独比较涉及模块和返回字段，再决定兼容分支或最低支持版本；更新 API 契约、矩阵和测试。
4. 验证记录注明客户端版本、服务端版本/commit、设备和场景，区分 Mock、模拟器、真实实例；不保存账号密码或完整签名 URL。

运行时版本识别目前未接入。v2.2.0 源码的 server.ts /js/config.js 通过 getBuildInfo 注入 version/buildHash；/api/status 属管理员接口。没有凭空添加 /api/version，也不为识别版本索要管理员凭据。后续接入公开版本信息时单独核对封装与构建差异，并允许“未知”，不盲目阻止登录。

私人歌曲删除/复制/排序已核对固定 v2.2.0 快照契约并通过 Mock，真实部署写入及多设备可见性待验收；不能据此宣称原平台公共歌单可写。
