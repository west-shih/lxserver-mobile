# 产品大纲

## 核心使用流程

配置服务器 → 完成鉴权（若服务端要求）→ 搜索或浏览音乐 → 加入队列 → 播放。

## 页面规划

| 页面 | 主要内容 | 阶段 |
| --- | --- | --- |
| 服务器连接 | 地址、连接检测、鉴权、错误提示 | 最小版本 |
| 搜索 | 平台选择、关键词、分页、播放入口 | 最小版本 |
| 播放页 | 封面、歌曲信息、进度、播放/暂停、上一首/下一首 | 最小版本 |
| 播放队列 | 当前队列、切换歌曲、移除歌曲 | 最小版本 |
| 迷你播放器 | 当前歌曲与快捷控制，跨页面保持状态 | 最小版本 |
| 我的音乐 | 歌单、收藏、最近播放 | 后续 |
| 歌单详情 | 歌曲列表、整单播放、编辑能力 | 后续 |
| 发现 | 排行榜、服务端支持的歌单入口 | 后续 |
| 下载管理 | 下载进度、失败重试、离线歌曲 | 后续 |
| 设置 | 服务器、音质偏好、缓存管理、版本信息 | 分阶段 |

页面结构是初始方案，导航形式在最小版本实现时确定。

## 功能边界

- 最小版本只要求稳定完成连接、搜索、播放和基础队列。
- 所有页面考虑加载、空数据、网络失败和可重试状态。
- 歌曲需保留来源平台及服务端标识，避免仅用标题判定同一首歌。
- 先验证后台播放与系统媒体控制，再扩展大量浏览页面。
- 收藏、歌单编辑和同步以实际服务端能力为准。
- 缓存是可清理的加速数据；下载是用户主动保存的数据，两者管理规则分开定义。
- 离线编辑和冲突合并不作为最小版本要求。

## 暂不纳入首版

多音乐服务适配、社交、推荐算法、桌面端、复杂插件体系。
