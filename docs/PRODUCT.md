# 产品大纲

## 核心使用流程

填写服务器地址、账号、密码 → 普通用户登录 → 五平台搜索 → 点击歌曲 → 播放。

## 第一版确认方向

- Android 优先，业务代码和音频/存储依赖保留 iOS 支持。
- 必须登录，不提供游客绕过、注册或管理账号配置。
- 服务器地址由用户输入，并在本机保留；账号由服务管理员预先创建。
- 第一版不提供后台和服务端设置；后续按需开放客户端偏好。
- 搜索平台为酷我、酷狗、QQ、网易、咪咕，逐平台检索，保留来源字段。
- 用户搜索平台与服务端用于解析播放地址的自定义音源是不同概念，客户端不管理自定义音源。

## 移动端设计

- 参考网页端白色、薄荷绿和圆角，重新组织移动端布局，不复用桌面表格或侧边栏。
- 弹窗表单使用共用主题。输入内容和下拉值用 14 号正文色，字段标签和占位提示用同字号的辅助文字色，字段下方的使用说明用 12 号辅助文字色。弹窗标题用 18 号，主要按钮用 14 号。
- 搜索与歌单页左上方仅保留紧凑搜索框，不重复品牌、大标题和宣传文案；“我的”使用小标题。
- “全部”聚合搜索、平台与分类筛选随列表滚动离开屏幕，顶部小搜索框保持可用。
- 歌曲行突出封面、标题和歌手；点击行播放，队列操作收进更多菜单。
- 歌曲行第二行依次展示平台、最高已标注音质、歌手；标签固定在前，长歌手名省略。普通字号保持两行，不把平台可选档位当作歌曲已拥有音质。
- 本机有完整文件时，在音质后显示“已缓存/已下载”；服务器文件放在「… → 信息」中单独查看。普通字号保持紧凑，大字号/极窄屏允许标签换行。配色对齐 LX v2.2.0。
- 底部迷你播放器仅显示当前歌曲、播放/暂停和队列；点击展开独立播放页。
- 头像进入独立个人中心，以账号渐变卡片、下载/缓存容量卡片组织信息；缓存设置和退出/切换服务器集中于此。
- “我的音乐”右上角提供本机下载入口，移除重复刷新按钮，列表保留下拉刷新。
- 播放页封面/歌词共用歌曲信息区：标签只读，音质切换放在播放页“…”菜单，列表菜单不显示音质，外部仅保留平台/当前实际音质/本机文件标签，与列表共用组件。顶栏只留封面、歌词和队列。歌名、作者、标签纵向组成紧凑信息组（间距 6 / 8），右侧更多按钮独立排布，不撑高标签行。
- 主控从左至右为播放模式、上一首、播放/暂停、下一首、评论。顺序播放用同向双箭头；模式包含顺序、列表循环、单曲循环、随机，本机记住选择。
- 四种模式图标统一使用紧凑圆头线条；选择面板使用圆角选项，当前模式以薄荷绿底和勾选标识，播放模式行为保持不变。
- 评论以可关闭的底部面板展示当前打开歌曲的最热/最新评论、点赞数与已有回复，显示可用头像和配图，配图可点击预览；沿用列表浏览设置连续加载或分页，支持下拉刷新和失败重试；仅浏览，不提供发表或点赞。
- 评论排序沿用歌单的紧凑下拉样式，与歌名和平台同一行靠右，左侧计数只显示「X 条」。搜索类型和缓存容量下拉同样使用实心向下三角。短列表面板随内容收紧，长列表在面板内滚动。
- 底部导航为“搜索 / 歌单 / 我的”；播放页左右滑动或点击标题切换封面/歌词，支持自动高亮及点击跳转。
- 封面和歌词共用一套进度与播放控制，顶部仅保留收起、页签和队列入口。页签文字与队列图标垂直居中对齐，选中线独立绘制在文字下方。
- 播放页“…”中的“音质选择”打开选择面板，该入口紧邻“信息”上方，菜单不显示“立即播放”，列表标签和播放页标签保持只读；首选音质默认无损，在个人中心独立设置和保存；面板保持打开并显示请求结果，以服务器标注展示播放音质。
- 主列表只展示歌曲具体标注、服务器已有文件或当前播放确认的音质。信息不完整的其他平台档位折叠到“尝试其他音质”，可信完整列表明确未包含的档位不显示；某次解析失败不当作永久不支持。全局首选保持独立。
- 首选不可用时同平台逐档降低，提示实际播放音质，保留首选；不自动跨平台替换歌曲。
- 新搜索音质列表明确时跳过未标注档位；每档优先服务端已有文件、有效地址，同档换解析源后再降级。手动切换仅影响本次播放，不修改全局首选或长期成功档位；个人中心修改首选后重启恢复。下载音质单独选择，不影响播放设置。面板提示标注大小仅供参考，网络整体不可用时不逐档重试。
- 收藏/搜索歌曲一旦成功播放，下次沿用已成功档位，不按 6 小时自动探测高档；链接过期只更新同档地址。修改首选、主动重试、原档位失败，或记录因注销/源配置变化/容量淘汰失效时重新选择。
- “我的”展示服务器个人收藏歌单、歌手和专辑。「歌单」分类可从顶栏下载图标左侧新建私人歌单；「收藏到歌单」弹窗也可直接创建并加入所选歌曲。
- 未实现的收藏编辑等能力不放置假交互入口；下载入口对应真实本机任务。

## 页面规划

| 页面 | 主要内容 | 阶段 |
| --- | --- | --- |
| 服务器连接 | 地址、连接检测、鉴权、错误提示 | 最小版本 |
| 搜索 | 平台选择、关键词、分页、播放入口 | 最小版本 |
| 播放页 | 封面、歌曲信息、进度、播放/暂停、上一首/下一首 | 最小版本 |
| 播放队列 | 当前队列、切换歌曲、移除歌曲 | 最小版本 |
| 迷你播放器 | 当前歌曲与快捷控制，跨页面保持状态 | 最小版本 |
| 我的音乐 | 歌单、收藏、最近播放 | 后续 |
| 歌单详情 | 歌曲列表、整单播放、编辑能力 | 后续 |
| 发现 | 排行榜、服务端支持的歌单入口 | 后续 |
| 下载管理 | 下载进度、失败重试、离线歌曲 | 前台流程已实现 |
| 设置 | 服务器、音质偏好、缓存管理、版本信息 | 分阶段 |

页面结构是初始方案，导航形式在最小版本实现时确定。

## 功能边界

- 最小版本只要求稳定完成连接、搜索、播放和基础队列。
- 所有页面考虑加载、空数据、网络失败和可重试状态。
- 歌曲需保留来源平台及服务端标识，避免仅用标题判定同一首歌。
- 先验证后台播放与系统媒体控制，再扩展大量浏览页面。
- 收藏、歌单编辑和同步以实际服务端能力为准。
- 缓存是可清理的加速数据；下载是用户主动保存的数据，两者管理规则分开定义。
- 离线编辑和冲突合并不作为最小版本要求。

## 暂不纳入首版

多音乐服务适配、社交、推荐算法、桌面端、复杂插件体系。

## 手机缓存与下载（当前实现）

列表文件徽标仅指手机完整文件；服务器状态从歌曲「… → 信息」查看。「我的」提供本机下载及缓存设置。完整行为与当前限制见 [LOCAL_MEDIA.md](LOCAL_MEDIA.md)。

播放、暂停、上一首、下一首及评论使用统一 PlaybackGlyph 圆角矢量图形；中央保留圆形绿色按钮，评论为圆润描边气泡。迷你播放器复用播放/暂停图形。

歌曲“信息”打开“存储”面板，仅分本机与 LXServer 两组。本机文件显示大小，点击已缓存条目确认清理；播放占用延后到切歌，下载与服务器文件受保护。音质面板以选项勾选/颜色表示当前档位，移除重复“当前音质”和“本机文件”状态提示。

下载任务和已下载列表显示来源平台标签；已下载封面优先从本机加载，成功保存后支持离线。缓存采用普通 LRU，不额外优先清理未选音质。

重新打开恢复当前队列、歌曲、音质和进度，保持暂停；点击播放才加载音频并继续。离线恢复可用本机资源，退出登录或清空队列会清掉恢复状态。存储面板移除“点击已缓存的音质可清除”提示，保留点击清理操作。
