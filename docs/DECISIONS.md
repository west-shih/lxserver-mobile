# 技术决策记录

只记录对后续开发有影响的决定，待定项不视为已采用。

## D001 客户端定位（已确定）

- 决策：使用 Flutter 构建 Android/iOS 客户端，优先适配 LXServer 原生 API。
- 理由：以完整服务端能力与移动端体验为核心。
- 影响：不以 Subsonic 兼容接口作为主要数据模型。

## D002 开发与验证顺序（已确定）

- 决策：使用现有 IDEA 环境，先验证 Android 播放闭环，同时保持平台边界。
- 理由：当前开发环境是 Windows，尽快得到真实运行反馈。
- 影响：iOS 功能最终必须在 macOS/Xcode 和真机验证。

## 待定清单
