# LXServer Mobile

A Flutter-based mobile music player built specifically for LXServer.

基于 Flutter 开发的 LXServer 专属移动音乐客户端，目标支持 Android 和 iOS。

## 项目目标

- 完整适配 [LXServer](https://github.com/XCQ0607/lxserver) 原生 API。
- 支持多平台音乐搜索、排行榜、歌单与收藏。
- 支持音乐播放、歌词、音质切换及后台播放。
- 支持移动端本地缓存与下载。
- 与 LXServer 保持歌单和用户数据同步。
- 提供符合 Android / iOS 使用习惯的移动端体验。

**项目原则：优先实现 LXServer 的完整能力，而不是追求兼容更多音乐服务。**

本项目是独立开发的第三方客户端，非 LX Music 或 LXServer 官方项目。

## 当前状态

已创建 Flutter Android/iOS 工程，实现登录、按用户音源状态筛选平台、聚合/单平台搜索、基础前台播放、
收藏与个人歌单只读浏览、在线歌单分类/搜索、基础同步歌词与音质选择。
界面采用白绿配色和“搜索 / 歌单 / 我的”导航，共用底部迷你播放器与独立播放页。
搜索与歌单页使用紧凑顶部搜索框，筛选随列表滚动，不重复大标题与宣传文案。
播放页左右滑动切换封面/歌词，共用进度与播放控制；默认偏好无损，并记住客户端音质选择。
播放页标签与列表共用，标签只读，播放页更多菜单提供音质切换；支持四种播放模式并保存选择，以及原平台最热/最新评论只读浏览。
首选音质失败后同平台尝试较低音质，提示实际结果并保留首选偏好，不自动跨平台换歌。
新歌曲按已标注音质选择档位；已成功歌曲长期沿用原档位，播放地址短期内存复用，支持手动重新尝试首选。
同档位优先服务端已有文件；链接失败先尝试其他同平台解析源，再降级。当前歌曲手动切换仅影响本次播放；个人中心独立保存全局首选，自动降级不会覆盖。
音质面板将未知档位折叠；列表仅显示手机本机“已缓存/已下载”徽标，平台/音质配色对齐 LX v2.2.0。服务器文件状态移至歌曲「… → 信息」。
接口依据上游源码实现；尚未使用真实部署实例完成端到端联调。
已实现手机自动音频缓存、主动下载、下载列表与缓存容量设置；收藏/歌单编辑写入与后台媒体控制尚未实现，后续目标不代表已完成能力。

```powershell
flutter pub get
flutter run -d emulator-5554
```

登录时填写自己的服务器地址、管理员已创建的普通用户账号和密码。
客户端不提供注册、后台管理或服务器音源配置。

## 开发环境

当前开发基线为 Flutter 3.47.9 stable、Dart 3.13.7、IntelliJ IDEA 与 Flutter/Dart 插件。
先在 Android 真机验证核心流程；iOS 构建和调试需要 macOS 与 Xcode。
运行步骤和平台限制见开发指南。

播放内核、缓存去重、失效与淘汰规则见 [PLAYBACK_ENGINE.md](docs/PLAYBACK_ENGINE.md)。
